# 𝗘𝗟ِ 𝙂𝗥𝗘𝗠ِ𝘼𝘼 — Website

موقع عربي متجاوب باسم 𝗘𝗟ِ 𝙂𝗥𝗘𝗠ِ𝘼𝘼، وصاحب الموقع/التيم 𝗶𝗥𝙃َ𝘼𝘽ِ𝗬.

## الملفات
- `index.html`: محتوى الموقع.
- `style.css`: التصميم الأسود والأخضر النيون.
- `script.js`: قائمة الموبايل والسنة الحالية.

## قبل النشر
1. افتح `index.html`.
2. ابحث عن `href="#"` في قسم التواصل.
3. استبدل الرابط الأول برابط حساب تيليجرام العام، والثاني برابط القناة.
4. احفظ الملف.

## النشر مجانًا باستخدام GitHub Pages
1. سجّل الدخول إلى https://github.com/ أو أنشئ حسابًا.
2. اضغط `+` ثم `New repository`.
3. سمِّ المستودع مثلًا `el-gremmaa-site` واختر `Public`، ثم أنشئه.
4. افتح المستودع واضغط `Add file` ثم `Upload files`.
5. ارفع `index.html` و`style.css` و`script.js` و`README.md` (أو ارفع محتويات المجلد، وليس ملف ZIP فقط).
6. اضغط `Commit changes`.
7. افتح `Settings` ثم `Pages`.
8. تحت `Build and deployment` اختر `Deploy from a branch`.
9. اختر الفرع `main` والمجلد `/(root)` ثم `Save`.
10. انتظر قليلًا ثم افتح رابط الموقع الذي يظهر في صفحة Pages. غالبًا يكون `https://YOUR-USERNAME.github.io/el-gremmaa-site/`.
